# Security Policy

## Supported Versions

Bu proje statik bir istemci uygulamasidir. Ana dalda yayinda olan son surum desteklenir.

## Privacy Model

Uygulama yuklenen XML veya ZIP dosyalarini sunucuya kaydetmez. Donusturme, on izleme ve PDF indirme islemleri tarayici icinde yapilir.

Guvenlik bildirimi yaparken mumkunse su bilgileri ekleyin:

- Etkilenen dosya veya akis
- Beklenen davranis
- Gerceklesen davranis
- Sorunu tekrar uretmek icin minimal ornek

Hassas XML, fatura veya kisi/kurum verilerini herkese acik issue'lara eklemeyin.
